# Production env checklist

Fill these **on the server** before `npm run build` / `npm run start`. Do not commit real secrets.

Set `NODE_ENV=production` (and optionally `MAKER_ENV=production`) so the API rejects weak `dev-` / `change-me` secrets.

## Files

- `Apps/api/.env`
- `Apps/web/.env.local`
- `packages/database/.env` (keep `DATABASE_URL` in sync with API)

## Must change (currently localhost / change-me / dev-)

| Key | File | Production value |
|-----|------|------------------|
| `JWT_SECRET` | api | long random secret |
| `BOT_TOKEN_ENCRYPTION_KEY` | api + database | long random secret (same both files) |
| `PROVISION_API_KEY` | api | long random secret (legacy provision only) |
| `BOT_INTERNAL_API_KEY` | api | long random secret |
| `CORS_ORIGIN` | api | `https://YOUR_DASHBOARD_DOMAIN` (comma-separated if multiple) |
| `DASHBOARD_PUBLIC_URL` | api | `https://YOUR_DASHBOARD_DOMAIN` |
| `NEXT_PUBLIC_APP_URL` | web | `https://YOUR_DASHBOARD_DOMAIN` |
| `DISCORD_REDIRECT_URI` | api | `https://YOUR_DASHBOARD_DOMAIN/api/auth/discord/callback` |
| `DATABASE_URL` | api + database | production Postgres URL |
| `REDIS_URL` | api | production Redis URL |
| `MONGODB_URI` | api | production Mongo if still used |
| `MAIN_BOT_TOKEN` | api/bot | control-bot token (overrides `Main/Resources/Config.json`) |
| `MAIN_LOG_BOT_TOKEN` | api/bot | logging-bot token (overrides `Errors.Token`) |
| `OPENAI_API_KEY` | api/bot | OpenAI key used by AI features |
| `MAKER_WEBHOOK_TOKEN` | bot | replaces `Configure.WebhookDM.Token` |
| `INTERNAL_API_URL` | api | `http://127.0.0.1:4000/api` (local loopback is fine) |

## External shop (Partner API) — required

| Key | Notes |
|-----|--------|
| Partner keys in DB | `npm run partner:create-key -w @maker/api -- "Shop Name"` |
| `PARTNER_HMAC_MAX_SKEW_SEC` | default `300` |
| `PARTNER_RATE_LIMIT_PER_MIN` | default `60` |
| `PARTNER_MAX_DURATION_DAYS` | default `3650` |
| `DASHBOARD_PUBLIC_URL` | must be public HTTPS — returned in `dashboardUrl` |

Docs: [Apps/api/docs/PARTNER_API.md](Apps/api/docs/PARTNER_API.md)

Shop backend base URL: `https://YOUR_API_HOST/api/partner/v1`

Keep `NEXT_PUBLIC_API_URL=/api` so the browser hits the same origin; Next rewrites `/api/*` to Nest `:4000`.

## Discord Developer Portal

Set OAuth2 redirect to the same URI as `DISCORD_REDIRECT_URI`.

## Network

- Public: nginx → web `:3000` only (API reached via Next rewrite and/or private Partner URL).
- Do **not** expose Postgres `5432`, Redis `6379`, or `/api/internal/*` to the open internet.
- Partner HMAC calls: server-to-server from the shop backend only.

## Boot sequence

```bash
git config core.hooksPath .githooks   # enable secret-scan pre-commit hook
npm ci
# edit env files above
npm run scan:secrets                  # must be ✅ before committing
docker compose up -d postgres redis   # or external Postgres/Redis
npm run db:generate
npm run db:migrate:deploy
npm run db:import:tokens             # dry-run legacy token pools
npm run db:import:tokens:apply       # write them to PostgreSQL
npm run partner:create-key -w @maker/api -- "External Shop"
npm run build
NODE_ENV=production npm run start
```

Ports: web `3000`, api `4000`, Postgres `5432`, Redis `6379`.
