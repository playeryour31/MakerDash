# Maker — بوتات العملاء (Customer)

Runtime لبوتات العملاء (Apply, Muslim, Ticket, …) مع `Json-Database` كأرشيف/fallback.

إدارة التشغيل من الحلقة في `Maker/index.js` (تُقلع عبر `scripts/run-bot.js`).

**تنبيه:** مجلد `Maker/` ≠ متغير `MAKER_ROOT` في Nest (ذلك يشير لجذر الريبو).  
انظر [docs/BOTS.md](../docs/BOTS.md).
